# AtomX

最新导入/导出与粒子外观修复说明见 [I/O 和粒子验证记录](docs/IO_AND_PARTICLE_VALIDATION.md)。应用已接入原生格式注册表、按格式显示选项的导出对话框、LAMMPS dump 轨迹、PDB/GRO 坐标读取，以及逐类型的真实三维粒子形状；下文历史功能说明尚未全部同步，以该验证记录的能力边界为准。

C++20 原生 Windows 原子可视化工作区，使用 Direct3D 11。界面参考 `vendor/zed` 的 One Dark 色彩、紧凑标签与面板布局。界面采用用户提供的 AtomX Logo、紧凑工具栏、三列分类修改器下拉菜单和纯黑原子视窗。当前版本是可运行的开发版，**尚未全面对齐 OVITO，也未实现几亿原子的全量高效渲染**。

## 启动

双击根目录 `Run AtomX.cmd`，或执行 `build\AtomX.exe`。启动后显示 FCC Cu/Ni 晶体，无需准备输入文件。

```powershell
.\build\AtomX.exe
.\build\AtomX.exe "D:\simulation\trajectory.xyz"
.\build\AtomX.exe --adapter 1
```

显卡索引在 System 面板可见，默认选择专用显存最大的可用硬件适配器。本机索引 0 为 NVIDIA，1 为 Intel；其他电脑的索引可能不同。没有偷偷切换到 CPU 软件渲染。

## 已实现

- 单 / 四视口、六个方向与正交 / 透视相机，粒子与晶胞开关。
- XYZ / Extended XYZ 单文件多帧轨迹、拖入文件、后台索引 / 读取、取消、帧播放。
- ASE 常用结构交换格式：POSCAR/CONTCAR、CIF、LAMMPS data；导出会按扩展名选择对应格式，XYZ 仍支持多帧。
- GPU 实例化球体 impostor，16 字节原子记录、每块最多 1,048,576 原子；共享原子缓冲供所有视口使用。
- 原子预算内全量显示，超出时进行确定性 stride 采样，同时标示源数量、显示数量与 stride。
- 非破坏性修改器：轴向 Slice、类型选择、反选、清空、删除选中、平移、统一缩放、正交周期 Wrap、旋转、晶胞方向复制、坐标区间选择、编辑选中粒子类型；管线开关、前移与撤销/重做。
- 粒子坐标表、晶胞矩阵、原始注释、位置直方图 / min / max / mean。
- 后台空间分箱邻域配位数与距离聚类、邻域距离分布、全周期正交晶胞 RDF、CSV 分析导出；禁止对采样数据给出邻域分析结果。
- 活动相机 PNG 导出、处理后数据 XYZ 导出。
- 粒子外观形状：球体、圆盘、立方体、圆柱、spherocylinder；右侧 Render 面板可切换。

详见 [完整功能对齐表](docs/FEATURE_MATRIX.md) 和 [架构说明](docs/ARCHITECTURE.md)。未实现的算法在下拉菜单中灰显并说明开发状态，不能执行；所有已实现功能均无 Pro 或付费限制。

## 操作

### 创作模式

查看视口右键可复制为独立创作标签。创作模式支持右键拖动旋转、Alt＋右键平移、Shift＋Alt＋右键移动选中原子、Shift＋右键旋转选中原子（X/Y/Z 约束屏幕轴）；沿用中键旋转。Shift 点击添加选择，Ctrl 点击切换，双击按已有键选择连接片段。右键菜单在单击松开后出现。选中原子后可用“编辑坐标”切换笛卡尔与分数坐标，点击应用记录一步历史。

现场核对记录、已加入的操作及后续缺项见 [Materials Studio 创作功能核对](docs/MATERIALS_STUDIO_CREATION_AUDIT.md)。

绘制工具支持连续成链、黄色虚拟原子预览、点击已有原子吸附连键、双击结束、Esc 取消。右侧选择元素和单/双/三键；选中两个原子后可修改键级或断键。无起点时点击直接键循环键级。默认键长按共价半径设置，Alt 拖动向里、Shift＋Alt 自由键长；Alt 点击空白放置孤立原子，Alt 点击原子换元素。操作可撤销，删除原子保留其他键。

六边形工具绘制 4/5/6 元碳环：空白处放置、点击原子共用一个顶点、点击直接键共用两个顶点和一条键。按住左键拖动调整朝向，松开一次提交整个环，Esc 取消。Alt 按下时创建芳香环；芳香键以实线加虚线显示，可保存到 `.atomx`。新原子是碳，不自动加氢；不推断完整杂化、价态或晶体对称等价原子。环预览最多六个顶点，静止时复用预览，不复制结构或上传 GPU。

片段工具提供甲基、乙基、羟基、氨基、甲酰基、羧基、苯基及四种卤素，共 11 个程序生成的模板。浏览器按库分类，可搜索、旋转/平移/缩放预览，双击末端原子更换红圈连接点。“开始放置”返回同一创作视口：空白处放置完整封端分子；在孤立或末端原子上接枝时去掉模板的连接点原子，目标为末端 H 时同时替换该 H，目标为其他元素时保留目标。按住拖动调整朝向、松开提交一步历史、Esc 取消。没有完整价态、杂化或自动避碰优化。

在主视口选中一个只有一条直接键的末端原子，选择构建 → 定义片段，可把其整个显式键连接分量保存到自定义库。上限 512 原子，不支持跨周期边界的网络。片段库位于 `%LOCALAPPDATA%\AtomX\fragments`，每项为可独立打开的 `.atomx` 文档，所选末端原子是连接点。读取和保存异步执行；每次启动首次使用时加载，最多 128 个自定义文件 / 8 MiB，单项最多 1 MiB。各创作标签独立保存当前片段和连接点；文档记住库项键，跨机器使用自定义项时需同时复制对应库文件。

创作模式的修改菜单、右键菜单和右侧面板可打开运动分组：从选择创建命名分组、改名、选择整组、取消分组（保留原子），或在后台按显式键的独立连接分量自动分组。一个原子只能属于一组，最多 512 组；自动分组包含孤立原子，跳过含周期边界键的整个网络，不按距离猜测键。分组成员仍可手工编辑，整体移动入口选取全部成员并打开精准移动/旋转。具有有效 `Mass` 标量属性时可绕质心旋转，否则使用几何中心。分组有隐藏成员时须先显示全部才可从该入口整体移动。分组和名称随原生文档、历史及工作区快照保存，删除原子后自动保持成员索引；新绘制/接枝的原子不自动加入分组。超胞沿用原有编号，同编号的副本属于同一组，需重新分组才能分别操作；交换格式不保证保留分组名称。尚无 MS 的分组椭球显示与模拟求解器。

创作模式的视图菜单、右键菜单和右侧面板可打开“显示样式”：原有外观、线、棒、球棒和 CPK。默认作用于当前选择，未选中时作用于整个体系；勾选整个体系可统一外观。可混合样式，球/棒半径、CPK 比例、线宽是当前标签的共享参数；点击应用记录一步显示历史，不重算结构管线。CPK 按元素范德华半径绘球并隐藏该原子的对应半键，未知元素退回类型半径。线样式用微小点显示原子便于拾取，尚无 MS 的孤立原子十字和配位多面体。样式跟随标签、快照和 `.atomx` 保存，不修改显式拓扑；超出既有键预算时沿用降级显示。

创作工具栏、工具菜单和命令搜索支持测量 / 修改距离、角度和扭转角：依次点击 2/3/4 个原子，角度顶点为第 2 点；距离也可直接点击已有非周期键。绿色标记持续显示，活动标记为红色。点击标记后在空白处左拖，向上或右增大，向下或左减小；Alt 切换移动另一侧，Esc 恢复。右侧可输入精确目标数值、反向移动、隐藏或移除标记。修改按显式键划分独立片段，平移或旋转其中一侧，保持固定侧及其余片段不变；旋转同步旋转已有有限向量属性。闭环、其他连通路径或含跨周期键的移动片段拒绝修改；不同步晶体对称等价原子，不包含平面测量。测量按实际坐标计算，不取周期最短距离。标记最多 256 个，随各标签、历史、快照及原生文档保存。Del 在测量模式有活动标记时移除标记，否则沿用删除原子的操作。

创作模式下 Ctrl+S 首次选择 `.atomx` 保存路径，后续 Ctrl+S 原子替换该文档；Save As 可另选路径。原生文档保存原子、显式单/双/三/芳香键、晶胞、科学属性、隐藏/标签、选择、相机和逐类型外观，重开后直接恢复独立创作标签。当前仅保存计算后的结果，不保存修改器步骤、撤销历史、工作区快照或其他标签。外部自定义粒子网格资产不嵌入文件。XYZ、POSCAR 等仍作为结构交换格式，不能恢复手工键级；`.atomx` 不是 MS 的交换格式。详见 [原生文档格式](docs/ATOMX_DOCUMENT_FORMAT.md)。

选中一个或多个原子后，右侧面板或右键菜单的“精准移动 / 旋转”可按 Å 或视图比例进行六方向移动，并按指定角度绕选中中心旋转。支持屏幕轴和体系 XYZ 轴，默认角度 45°；每次点击只记录一步历史，晶胞和未选中原子保持原值。

“隐藏选中”“仅显示选中”和“显示全部”控制当前创作标签的可见性；隐藏原子及相关键停止绘制和拾取，不删除结构数据。“原子标签”支持元素、编号（从 0 开始）、坐标与自定义文字，以及字号、颜色和粗体。未选中原子时默认作用于全部体系。标签默认关闭，开启后默认最多绘制 500 个，可调整上限。显示状态可撤销/重做，并随当前标签和工作区内存快照保存。

## 构建与测试

需要 Visual Studio 2022 C++ Build Tools、Windows SDK。Dear ImGui 1.91.9b 已包含在 `third_party/imgui`，无需安装 Qt、Python、CUDA 或 Vulkan SDK。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\build\core_tests.exe
.\build\AtomX.exe --smoke 120 --screenshot build\smoke.png
```

也提供 CMake 工程，可用 Visual Studio x64 generator 构建。`build.ps1` 是本机实际验证过的构建入口。发布使用动态 MSVC runtime，其他电脑若缺失需安装相应 VC++ 运行库。

性能记录和测试边界见 [验证报告](docs/VALIDATION.md)。约 60 FPS 的小场景结果不能外推为几亿原子能力。当前没有磁盘空间层次索引、按视锥流式驻留、误差受控 LOD、跨厂商自动化驱动回归或科学分析的全量 OVITO 一致性测试。

## 依赖

Dear ImGui MIT 许可证见 `third_party/imgui/LICENSE.txt`。Zed 源码保留在用户提供的 vendor 中，AtomX 构建不依赖它，也没有复制 Zed 的功能代码。UI 设计参考路径为 `vendor/zed/assets/themes/one/one.json` 与 `vendor/zed/crates/ui/src/styles/spacing.rs`。


外观配置保存于 `%LOCALAPPDATA%/AtomX/settings.ini`。主题不改变原子视窗的黑色背景，Render 页面仍可手动调整视窗背景。窗口支持标题栏拖动、双击最大化和边缘调整大小。关闭至托盘失败时自动最小化，避免窗口丢失。退出时取消并等待后台工作，再释放资源。

新增算法边界：Rotate 同时旋转坐标和晶胞；Replicate 按选定晶胞向量复制 1–32 次，总量限制为 2000 万；区间选择基于当前管线坐标；类型编辑作用于选中粒子。RDF 使用 128 个球壳，按 `2 × pair_count / (N × density × shell_volume)` 归一化，只对全周期正交晶胞输出。邻域距离分布不是基于显式键拓扑的 Bond length distribution。


## 阅读优先的 UI 更新

默认外观改为 Classic light、18 px 逻辑字号，并按启动显示器的 Windows DPI 缩放字体与主要布局。已保存的主题和字体选择保持有效。工作区侧栏通过工具栏 Workspace 展开；粒子表通过 Data inspector 展开，默认把面积留给黑色四视窗。

Trajectory 采用主/次刻度尺，自动选择 1/2/5 系列刻度间隔；所有帧号统一从 0 开始。支持拖动刻度尺、直接输入帧号、首/尾帧、前/后帧与播放暂停。键盘 Tab 可聚焦刻度尺后使用左右箭头和 Home/End。后台读帧期间保留最后一次定位请求，不再为普通逐帧读取弹出阻断操作的加载对话框。

修改器菜单使用三列独立卡片、加粗分类标题、白色内容区和清晰边框。深色主题也提高了正文和次要文字对比度。
