## 数据与性能约定

- 复制显式选择及直接选中键的可见端点；内部键、键级、原子科学属性、约束、运动组、完整测量标记和局部显示规则跟随片段。全局表和全局统计不作为片段数据复制。
- 保持笛卡尔坐标；不猜测位移、不自动接入目标体系，也不因粘贴自动补氢。新片段选中后可用移动工具定位。共享球棒半径、字体和类型样式沿用目标标签设置。
- 不兼容的属性类型或不同晶胞中的周期键 / 分数方向约束，在修改前拒绝。单次剪贴板最多 100,000 原子 / 64 MiB；粘贴一步撤销。
- `.atomx-project`保存所有标签源数据、四个相机、显示与选择、完整修改器参数、撤销 / 重做、创作快照、文档路径和轨迹引用。输出缓存、悬停 / 拖动预览、字体缓存和自定义外部网格不保存。
- 工作区最多 64 标签 / 2 GiB。外部轨迹未嵌入全部帧；校验大小与修改时间，不匹配时保留内嵌当前帧，避免用过期偏移读错数据。追加打开保留已有未保存标签。
- 保存 / 加载异步进行，失败不覆盖原文件；保存成功以同目录临时文件原子替换。原子预算沿用用户设置。
- 默认 GPU 渲染仍使用现有 D3D11 球体 impostor 与批量键。剪贴板、排序和工程序列化不放在每帧渲染循环中；未引入 NVIDIA 专用库或新增常驻进程。

## 本轮验证

测试入口：`tests/export_workflow.cpp`，实际 App、后台管线及 ImGui 指针 / 按键事件；另有核心、格式、对称 / 表面、POSCAR、渲染与样式测试。

新增检查包括内部键与科学属性复制、运动组编号隔离、不兼容列预先拒绝、粘贴单步撤销 / 重做、工程标签 / 快照 / 历史恢复、截断文件拒绝、异步追加打开、居中保留缩放、持续缩放与 Esc、多文件加载队列。原生验收文件：`build/noncalc-workspace-acceptance.atomx-project`，含 NaCl 查看 / 创作及 55,296 原子 Cu/Ni。

匿名菜单项、QSAR 组的具体命令、禁用的 Grid / Study Table / Chart / Scripting 文档工作流，以及所有未展开子项仍缺少行为定义。它们不计入本轮已确认功能完成列表，也不标为“已实现”。23 个 Modules / Calc 对话框按用户要求排除。上述边界不能换算成可信的 MS 全软件百分比。
