# Materials Studio 创作功能现场核对

### 原子模拟约束与方向标志（2026-10-04）

- 本机 MS、本任务自己的 `3D Atomistic (4).xsd`：在已有 Cartesian X 固定状态下，实际打开 3D Movement，使用默认 Screen 2% 的右移按钮，选中的下方 C 移动，C—C 长度由 1.540 变为 1.424。再点击左移，长度恢复 1.540，三条 C—H 长度恢复 1.140；随后重新打开 Constraints，解除本任务的 Cartesian 标志。验证了模拟约束不会阻止手工移动。没有操作用户结构或 MS Calc。
- 实际打开本任务的倾斜二维周期结构 `ms-layer-skew.xsd`、选择 O 并进入 Modify → Constraints：Fix fractional position 可用；此前非周期碳结构中该控件禁用。此处仅查看，没有设置分数约束。安装帮助 `core/tools/dlgeditconstraintsatom.htm` 说明部分 Cartesian 轴、旋转后方向与 Atom / Measurement / Lattice 页；本次没有实测右键组合拖动，也没有宣称整个约束工具已对齐。
- AtomX 新增“原子模拟约束”，可从右侧选中面板、修改菜单和原子右键打开。整原子 Cartesian XYZ 固定使用独立的 `AtomX.FixedCartesian` 标志；晶格 a/b/c 分数分量使用现有 `MoveMask`（1 自由、0 固定）。单选、多选显示共同或混合状态；默认“保持当前值”不覆盖未修改的混合分量。整原子固定不是部分 Cartesian 轴约束，界面明确标出此限制；有效可逆三维晶格且存在周期方向时启用分数约束，奇异二维基矢尚未支持。
- 约束是模拟元数据，不禁止手工移动或旋转，也不执行求解。修改前校验选中行、全部约束列类型/长度/二进制值和捕获的标签/源版本；同值不写历史，有变化只记录一步结构历史。保留未选行、坐标、键级和 Charge/Force 等科学属性，不自动补氢。撤销/重做、独立标签与 `.atomx` 保存重开沿用现有结构机制。
- `MoveMask` 是晶格分量标志，不是空间矢量，Affine、角度/二面角修改、补氢和片段旋转不再旋转它。新增环、氢、片段和层中缺失约束行默认自由；超胞复制和删除压缩保留原有标志。片段库不保留来源晶格、层匹配会重建基矢，因此存在非自由分数约束时明确拒绝这两类操作，避免把来源约束错误套到新晶格。
- POSCAR 的 Selective dynamics T/F 对应直接晶格方向，与坐标行选 Cartesian 或 Direct 无关，依据 [VASP 官方 POSCAR 说明](https://vasp.at/wiki/index.php/POSCAR)。保留分数标志；整原子 Cartesian 固定在晶格变化时不能由这些标志忠实表达，默认导出在覆盖文件前拒绝，用户可保存 `.atomx` 或显式取消约束保留。没有静默转换为 F F F。
- 核心测试覆盖混合多选、同值、非法列、自由新行、手工移动、Force 旋转与 MoveMask 不旋转、补氢/环/片段、超胞、删除、层默认及基矢重建拒绝。格式测试覆盖倾斜晶胞的 Cartesian POSCAR 坐标与分数标志、导出拒绝和原生双类标志；真实 ImGui 事件覆盖选择组件、取消/无操作、历史、失效源、保存重开及带固定标志的精准移动按钮。核心、格式、应用事件测试与原生构建均通过。
- 原生 AtomX 实际对自建三原子夹具的中间 C 设置整原子固定、解除 c 分量固定，保存独立读回得到 Cartesian=1、MoveMask=(0,1,1)，其他行、坐标、Charge、Force 和单键/三键保留。Ctrl+Z 后保存确认恢复 Cartesian=0、MoveMask=(0,1,0)；点击重做并再次保存，读回恢复编辑结果。修复验收中发现的下拉文字截断，最终构建重新打开文件核对状态。`AtomX.exe` 和 `AtomX-next.exe` 的 SHA256 均为 `ECD59AEF36CA32C1712857E2AFCA4F60A2094794EA5FFC7352CA22B415B3B23F`。
- 约束统计在打开时读取，不为静止渲染增加全量扫描；提交仍有现有 Dataset 历史和管线更新成本。没有新增运行依赖或改变 D3D11 GPU 渲染。部分 Cartesian 方向约束、Measurement / Lattice 约束、完整 Properties Explorer 与周期几何编辑仍待继续现场核对，持续目标保持，MS Calc 排除。

### 独立键可见性（2026-10-04）

- 本机 MS、本任务自建的 `3D Atomistic (4).xsd`：只选中心 C—C 键时，Display Style 显示 “No display style properties available”。没有据此添加或宣称 MS 支持独立键的 Line/Stick/颜色属性。右键 Hide 实际使中心键和它的长度标注消失，六条 C—H 连接保留；Ctrl+Z 恢复。重新只选中心键后执行 Show Only，其他原子被隐藏，画面只剩 1.540 长度标注；再次 Ctrl+Z 恢复完整夹具。安装帮助 `core/viewers/structurevisibility.htm` 补充 Hide / Unhide / Show Only 的对象可见性规则。没有删除 MS 对象，没有操作 MS Calc。

- 键可见性使用默认规则及端点/周期像身份例外，键级不参与身份；重排、反向存储和改键级保留显示设置，删除端点重映射，断键清除过期例外。GPU 上传按实际输出键身份判断，管线输出重排不会把隐藏标记误附到同一行的另一条键。隐藏键同时排除绘制、拾取、高亮和标签。

- 默认键可见性没有逐键缓存；局部身份例外不超过既有交互预算，源拓扑超过预算不建立逐键索引缓存。局部规则存在时，提交/恢复仍需要扫描拓扑，GPU 可见性改变仍更新缓冲；静止帧不重建规则或拓扑，沿用 D3D11 GPU，没有新增运行包。键渲染预算仍按源拓扑保守计算，不因隐藏而绕过超大键网络的保护。

### 精准移动验收

- 平移与旋转只改变选中的原子，晶胞和未选中的原子保持原值。普通精准移动默认绕所选原子的几何中心旋转；有有效 `Mass` 属性时可选择质心。单原子绕自身旋转不创建无效历史。
- 视图比例以打开对话框时较短边、所选原子中心的投影深度换算。打开期间保留该比例；重新打开会按当前视图重新换算。该规则适用于透视和正交视图。
- 每次方向按钮记录一步历史，可连续操作；关闭后可撤销/重做。弹窗接管快捷键，防止在输入数值时改变底下的选择或标签。

## Layer Builder 现场核对与实现

- 首轮实际打开本机 MS 的 Build → Build Layers，查看 Define Layers、Layer Details、Matching、Options 四页；移动原先部分越出屏幕的窗口后核对选项。当时临时非周期分子没有可用来源，因此该阶段未在 MS 中执行构建。后续周期来源的实机构建见下节。
- 几何规则据已安装官方帮助 `core/builders/layers_overview.htm`、`dlglayerbuilderdefine.htm`、`dlglayerbuilderdetails.htm`、`dlglayerbuildermatching.htm`、`dlglayerbuilderoptions.htm`、`surftaskslayer.htm`、`crysttaskslayer.htm`：两至三层、层上方真空、分数面内偏移、任选来源/平均 a、b、γ、保持体积/厚度、来源朝向、5% 失配提示。MS 默认完整分子切割、A/B 翻转及模拟用 Confined shear 与本轮实现有区别。
- AtomX 入口为创作模式“构建 → 构建叠层”，查看模式 Build → Build Layers，或 Ctrl+P 搜索 Build Layers。查看模式入口先创建独立创作副本。结果替换当前创作体系并记录一步历史，来源标签保留；可暂存工作区快照。来源为所选标签当前帧的源数据；修改器结果须先创建创作副本。
- 支持右手 3D 晶体及 a/b 周期的 2D 表面，禁止采样与退化晶胞。晶体先按周期归一化到单胞；面内匹配时分数坐标不变，c 的面内分量随晶格变换，保持体积时以旧/新面内面积调整法向厚度。晶体输出沿调整后的 c 累积，表面输出沿法向累积；每层上方真空均沿法向增加，表面输出忽略末层真空。表面来源以原子法向跨度为厚度，去掉原来源的外部真空；零厚度单原子层需非零层间真空。
- 保留元素、显式键级和面内周期键，并随面内归一化重算键周期像；切断层的法向边界键，不推断新跨层键。合并各层标量/矢量属性并保持原子行对应，缺失值补 NaN；完整自定义颜色保留。矢量值保持来源语义，不自动猜测 Force/Velocity 等任意列的应变变换；源/目标基底保存于 `AtomX.LayerBases` 表。全局属性与普通表按 Layer1/2/3 命名空间保存，避免伪造合并总能量等值。运动分组编号按来源重新分配。
- `AtomX.Layer` 标记层成员，`AtomX.Layers` 保存名称、起始原子、数目、真空、偏移、厚度及失配；它们使用现有科学属性格式随 `.atomx` 保存，不升级文档版本。输出为 P1 / p1，不沿用来源的对称关系。
- 构建只在点击时复制来源快照并启动后台任务；普通 UI 预览只访问晶格和原子数，不逐原子扫描或生成邻居。采用当前完整载入原子上限，不沿用旧叠层 60000 限制。不添加运行时包或更换 GPU 渲染路径。
- 核心测试验证斜晶胞、非零原点、保持体积/厚度、面内偏移的周期键像、三层朝向、表面去真空、零厚度单层、来源隔离、元素/属性/分组保留、非法输入及 140000 原子叠层。真实 ImGui 按钮测试验证后台构建、同标签一步历史、撤销/重做、源标签不变、文档保存及失败不产生历史。GPU 回归仍在 NVIDIA RTX 5090 D v2 上通过。
- 首轮尚未实现完整分子切割和 Flip A/B，后续已补齐，见下节；自动超胞共格搜索、约束求解器及跨层自动键合仍未实现。MS Calc 工具栏组按用户要求排除。
- 原生验收用两个独立 XYZ 标签（FCC Cu 3.615 Å、Ni 3.520 Å），从查看菜单打开 Build Layers，生成独立创作标签。默认平均面内晶格 + 保持体积 + 两层各 3 Å 上方真空得到 8 原子、a=b=3.5675 Å、c=13.1388 Å；原生 Ctrl+Z 恢复 Ni 四原子，Ctrl+Y 恢复叠层。Ctrl+S 保存本任务 `build/layer-acceptance.atomx` 后重启最终原生构建，确认 8 原子和晶胞恢复。最终构建成功自动关闭叠层对话框，另一次重复来源构建及撤销验证后留在保存的 8 原子结果。

### 完整分子切割与层翻转

- 后续现场操作在 MS 中通过 File → Import 导入本任务的 P1 斜晶胞（a=6、b=7、c=10 Å、γ=60°，C/O 两原子），在 Build Layers 的 Layer Details 中实际选择 Flip A。Matching 页显示 γ=120°，点击 Build 后生成独立 Layer.xsd；仅保存本任务的新结果，未改动用户原有文档，也未使用 MS Calc。
- 已安装官方帮助明确 A/u 对应 a、−b、−c，B/v 对应 −a、b、−c，匹配角取 180°−γ；Default 切割按分子质心归属保留连通原子，以暴露原子的范德华半径修正厚度。MS 测试结果 c=8.220000 Å，符合两个原子法向跨度 5 Å 加 C/O 半径 1.70/1.52 Å。现场的单层结果所存 A/B 矢量夹角仍为 60°，与 Matching 显示值不同；此差异尚未解释，不能声称已验证 MS 所有输出朝向与 AtomX 完全一致。AtomX 采用上述官方补角规则，斜晶胞测试验证翻转后匹配无额外应变、键长保持。
- AtomX 每层增加“原子切割 / 完整分子（质心归属）”及“不翻转 / A/u / B/v”。表面来源不重复切割，翻转仍可用。完整分子仅由已有显式键及周期像确定；无键原子单独处理，不计算距离邻居。有限连通分量先展开周期像，再以质量加权质心整体归属单胞，不逐原子切断分子。具有非零周期绕数的无限键网络明确拒绝，用户可改用原子切割。
- 正且有限的逐原子 Mass 优先用于同位素/自定义质量；缺少该列时采用内置元素质量，数据对照本机安装的 MS 元素表。厚度使用 AtomX 现有 Bondi 范德华半径，不替换现有元素外观；部分元素与 MS 的半径表不同，缺少已用元素半径时拒绝完整分子切割。此功能不提供化学价态推断或跨层自动键合。
- 分子展开使用带周期偏移的并查集，辅助存储随原子数增长，不复制整张键邻接表。默认仍为快速原子切割，保持紧凑周期像缓存且不分配额外双精度坐标数组；只有完整分子/表面包络计算需要坐标缓存。扫描只在后台构建发生，普通参数预览不扫描原子。无新增运行依赖，保留现有 D3D11 GPU 路径。
- 翻转、展开与晶格匹配同时更新显式键周期像，保留键级和科学属性行对应；来源标签不被修改。Cleave/Flip 写入 AtomX.Layers 表，源/目标基底写入 AtomX.LayerBases，沿用现有原生文档格式。层参数及说明采用滚动区域，构建/关闭按钮保持可见。
- 核心测试新增跨 c 分子、质量改变质心归属、默认元素质量、有限周期环与不同连边顺序、无限网络拒绝及原子切割回退、缺失半径/非法质量、A/B 斜晶胞与表面翻转。真实 ImGui 事件实际选择完整分子/A、后台构建、一步历史、撤销/重做及原生文档往返；既有 140000 原子默认叠层测试继续通过。核心、界面、格式及实际 NVIDIA RTX 5090 D v2 GPU 回归通过。
