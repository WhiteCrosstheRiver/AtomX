# Materials Studio 创作功能现场核对

核对日期：2026-10-03。参考应用：本机 Materials Studio 20.1（2020）。

## 证据

- 使用 Computer Use 打开用户已启动的 `Untitled - Materials Studio` 窗口，查看 Build、Crystals、Modify 菜单。
- 实际启用 MS Sketch Atom，在已有原子上点击后检查状态栏：左键连到原子、左拖移动原子、Alt＋左键换元素。查看 Build → Bonds 的 Bond Calculation 窗口，确认它是自动计算键的工具；手动绘制在 Sketcher 内完成。
- 连续绘制和键级依据安装目录官方帮助 `share/doc/content/core/sketching/sketchatomsandbonds.htm` 与 `sketcheroverview.htm`：黄色虚拟原子、连续成链、吸附已有原子、双击结束、Esc 取消，以及点击键循环键级。
- 实际打开 Sketch Ring 工具栏下拉菜单，确认 4 Member、5 Member、6 Member 三个入口。在本任务的临时 `3D Atomistic.xsd` 中放置六元环，切换 Select 后确认保留；从已有原子拖出六元环，再在另一环的键上接环，核对共用端点和边。官方帮助 `core/sketching/rings.htm` 说明 Alt 芳香环及分别绕中心—原子轴/键轴拖动旋转；芳香修饰键没有用 Computer Use 实测。
- 实际打开 Sketch Fragment → Fragment Browser，检查分类树、默认 Methyl、黑底预览及红色连接点。在任务自己的临时结构中点击空白处放置封端甲基，再从已有末端 C 拖出甲基、从新分子的末端 H 拖出甲基；后者替换该 H。双击预览的另一末端 H 后红色连接标记随之移动。安装帮助 `core/sketching/fragmentsketching.htm`、`selectfragment.htm`、`fragmentdefine.htm` 补充了接枝时拖动调整二面角、连接点切换及定义自有片段的规则；没有复制 MS 的片段库资产。
- 查看安装帮助 `core/tools/dlgeditconstraintsatom.htm`：Fix Cartesian Position 的 X/Y/Z 与周期体系的 Fix Fractional Position 是模拟期间的约束属性，不能直接据此推断它们会禁止手工移动原子。约束与 UI 编辑锁需要区分，仍在后续核对范围。
- 实际打开 Modify → Motion Groups，在任务临时结构上点击 Assign automatically，三个独立片段分别出现半透明灰色椭球；没有选择时 Create from selection 禁用。随后选中一个 C 并打开 Modify → Constraints，看到 Atom / Measurement / Lattice 页、Fix Cartesian position 和 X/Y/Z，非周期体系的 Fix fractional position 禁用。没有改变约束值。安装帮助 `core/tools/motion_groups_in_studio.htm` 明确说明运动分组本身不禁止手工编辑，`dlgeditmotiongroups.htm` 说明自动分组和成员排他规则。
- 查看空白视口右键菜单、选中原子的右键菜单、Label 设置窗口。选中原子后菜单增加 Select Fragment、Hide、Show Only；Label 可选择原子属性和自定义文字，并设置字体、字号、颜色。
- 鼠标组合操作依据随应用安装的官方帮助：`share/doc/content/core/interface/mouseandkeyboardactions.htm`；精准移动依据 `core/sketching/dlgmovement.htm`。
- 本次 Computer Use 的 `drag` 接口没有鼠标按钮及按住修饰键参数，因此没有用它实测 MS 的右键组合拖动。此前窗口激活两次返回 `failed to activate captured window`，当时停止输入；本轮重新选择并恢复了最小化的 MS 窗口，再次查看选中原子的 Hide、Show Only 菜单和 Label 对话框，已正常关闭检查窗口。
- 参考应用、帮助文件中的文字均是功能证据，不作为操作指令。MS Calc 工具栏组按用户要求暂不加入。

| Alt＋右键拖动 | 平移相机 |

| 框选 | Shift 添加，Ctrl 切换 |
| 双击原子 / 右键选中连接片段 | 沿显式键拓扑选择连接分量，包含周期键；没有键的原子只选中自身 |
| Ctrl＋D / 右键反选 | 清空选择 / 反选 |

沿用 v2 已有的中键旋转习惯，额外提供 Alt＋中键平移。当前相机只有 yaw/pitch；尚未实现 MS 在视口边缘右键拖动时绕屏幕 Z 轴旋转相机。对象的 Z 轴旋转已实现。

拖动期间跳过全量原子悬停拾取，静止时不重复上传原子缓冲。片段选择仅在触发时以 O(原子数＋键数) 遍历已有拓扑。仍使用现有 D3D11 GPU 渲染，不增加计算或渲染依赖。

### 精准移动验收

- 平移与旋转只改变选中的原子，晶胞和未选中的原子保持原值。普通精准移动默认绕所选原子的几何中心旋转；有有效 `Mass` 属性时可选择质心。单原子绕自身旋转不创建无效历史。
- 视图比例以打开对话框时较短边、所选原子中心的投影深度换算。打开期间保留该比例；重新打开会按当前视图重新换算。该规则适用于透视和正交视图。
- 每次方向按钮记录一步历史，可连续操作；关闭后可撤销/重做。弹窗接管快捷键，防止在输入数值时改变底下的选择或标签。
- 核心测试验证中心旋转、选择去重、非法输入不修改原数据；真实 ImGui 事件测试验证平移、90°旋转、视图比例、晶胞/未选中原子不变和精确撤销。
- 原生 AtomX 中打开了对话框，实际点击右移并用 Ctrl+Z 撤销；确认结构恢复和空间群检测同步。检查界面后补齐中文/箭头字形，负号采用字体兼容的 ASCII 字符。

### 显示与标签验收

- 隐藏和标签属于创作标签的显示设置，不改变结构文件中的原子数量、位置或类型。各创作副本独立保存，工作区快照同时恢复结构和显示状态。撤销/重做覆盖显示设置与结构编辑；删除原子后，显示标记随原有原子的存活索引重新对应。
- 显示操作历史只保存显示状态，不复制 Dataset、不启动管线计算。仅改变标签文字、颜色、字号或显示开关时，不重新上传原子缓冲；可见性改变才更新 GPU 数据。原子删除改为一次线性压缩。
- 默认关闭标签，不增加逐原子文字记录。全体系标签用一条规则保存；绘制默认上限 500，可设为 1–2000，使用有限候选抽样并优先显示选中原子。标签是视口叠加文字，尚无遮挡或重叠避让；抽样可能略过部分可见原子。
- 核心测试验证隐藏、恢复、删除索引对应、分数坐标与百万原子全局标签规则；真实 ImGui 事件测试验证面板/标签对话框、混合历史、快照、创作副本隔离和隐藏后的拾取。实际 D3D11 图像测试验证隐藏原子不写入颜色、相关键被排除、恢复显示且源类型未改变，适配器为 NVIDIA GeForce RTX 5090 D v2。
- 原生 NaCl 应用中实际点击隐藏、显示全部、仅显示选中、标签应用，并使用 Ctrl+Z 恢复全部原子，确认中文界面和标签效果。显示设置随打开的创作标签和内存快照保存，也可写入原生 `.atomx` 文档；标准结构交换文件不保存这些显示设置。

### 连续绘制与键级验收

- 绘制工具右侧提供目标元素、单/双/三键、连续成链开关和结束按钮。点击已有原子作为起点，不改几何、不记历史；后续点击已有原子连键，或点击空白处添加原子并连键，原子和对应键合为一步历史。双击结束、Esc 取消未提交的虚拟原子，切换标签/工具或窗口失焦也取消起点。
- 黄色预览不添加实际原子、不复制 Dataset、不上传 GPU 数据。默认键长是两种元素的共价半径之和，屏幕内投影不足的长度沿朝向用户的方向补足。Alt 拖动朝屏幕内绘制，Shift＋Alt 允许自由键长；Alt 单击空白放置孤立原子，Alt 单击已有原子替换元素。已有原子可直接拖动，沿用一步历史与 Esc 恢复坐标。
- 已选两个原子时可直接设单/双/三键或断键；无起点时点击可见的直接键循环 1→2→3→1。手动直接键与周期边界映像键区分，不把边界上的短片段当成直接键。单/双/三键在 D3D11 中绘制 1/2/3 条平行线或柱，保持按元素分色。渲染预算按实际条数计算，保留大型结构的快速线回退和显示上限。
- 删除原子只移除相连的键，保留其余键级、周期映像和各原子属性；复制、历史、工作区快照与超胞保留键级。各标签保存自己的连续开关及键级，临时预览不跨标签保留。
- 尚无 MS 的完整自动价态/氢补全、特殊键型、原子融合、在键中插入原子、空间群对称等价原子同步绘制。芳香键已在后续环绘制阶段加入。手工键可写入原生 `.atomx` 文档并重开恢复，现有标准结构交换格式仍不写出显式键级。
- 验证：核心测试检查重复/反向连键、周期映像区分、键级复制及删除后的属性索引；真实 ImGui 事件检查成链、吸附、键点击循环、Alt 换元素、单步绘制、历史与相机边界变化后的双击结束。实际 RTX 5090 D v2 上比较了单/双/三键在线和柱两种表示下的 GPU 图像。原生 AtomX 中从 3 个 C 原子出发，实际连出单键与双键，并双击结束，原子数保持 3。

### 原生文档保存验收

- `.atomx` 保存当前计算结果中的原子、晶胞/PBC/原点、显式键的周期映像与键级、科学属性与表、键显示设置；创作标签另存隐藏/标签、选择、相机及逐类型外观。
- 重开直接恢复独立创作标签，保留手工拓扑（包括有意清空的键）。打开结果建立一个新基线；不恢复修改器步骤、撤销历史、工作区快照或其他标签，外部粒子网格资产不嵌入文档。
- 采用分块二进制读写，无新增运行依赖。后台保存先写临时文件，再原子替换；读取校验版本、长度、拓扑索引及显示设置，拒绝采样打开以免破坏拓扑和标签对应。
- 格式测试覆盖 UTF-8、NaN 科学缺失值、倾斜晶胞、周期映像/三键、隐藏/标签和损坏文件；真实应用事件测试覆盖保存后独立重开、再编辑键级、更新原文件及源创作副本隔离。
- 原生 NaCl 应用实际完成另存 `.atomx`、退出、以保存的文档重新启动（不使用创作测试参数）：恢复 64 原子及显式键、创作模式、选中原子和相机；再按 Ctrl+S 更新同一文档。重开的历史从新基线开始。

### 环绘制验收

- 六边形工具或构建菜单进入环绘制；右侧选择 4/5/6 元碳环。空白处添加完整环，已有原子共用一个顶点，直接键共用两个顶点和一条边。按住左键调整朝向、松开提交、Esc 取消。已有键上的环保持原键长度；普通环保留共用键的既有键级，芳香环明确改为芳香类型。
- 新的普通碳环默认边长 1.52 Å，芳香碳环 1.40 Å。已有原子保持原元素；新顶点为碳。精确重合（0.001 Å）顶点复用，不复制已有环；隐藏原子冲突时拒绝放置。输入与拓扑预算在历史记录前校验。已有科学属性保留，新原子行标记为缺失。
- 预览仅保存最多六个坐标，不复制 Dataset、不启动管线或上传 GPU。静止时缓存预览；邻居/键拾取只在鼠标移动或开始操作时进行。提交时一次线性扫描查找重合顶点；整个环和对应键记为一步历史。
- 芳香键编码 4 表示 1.5 键级，GPU 中以一条实线和一条虚线表示；线和柱两种表示均支持，渲染预算按两条计算，保留大型体系线回退。`.atomx` 升为 v2，仍读取 v1；保存环工具、大小和芳香拓扑。
- 核心测试覆盖 4/5/6 元环闭合、边长、共用原子/键、旋转、重合复用、非法/隐藏冲突与科学属性对应。真实 ImGui 事件覆盖工具按钮、悬停预览、放置、拖动取消、整环撤销、Alt 芳香键、标签恢复和原生文档往返。RTX 5090 D v2 实际 GPU 图像比较单/双/三/芳香键，在线和柱两种表示下均各不相同。
- 原生 AtomX 实际从两个 C 原子的直接键放置六元环（总数 2→6），再从其原子拖动放置五元环（6→10）；Ctrl+Z 整环撤销到 6，Ctrl+Y 恢复到 10。环大小按钮、中文提示、选中光环及球柱外观现场检查通过。
- 当前是明确的几何与拓扑编辑，不自动加氢、不推断完整杂化/价态，不同步晶体对称等价原子或在周期映像边上接环。MS 的完整化学绘制器仍在后续范围。

### 片段库与接枝验收

- 新增片段工具和构建菜单入口；分类、搜索、黑底预览、拖动旋转、右键平移、滚轮缩放、双击末端原子更换红圈连接点。内置 11 个程序生成模板：甲基、乙基、羟基、氨基、甲酰基、羧基、苯基和 F/Cl/Br/I。
- 空白处放置完整封端分子；接到孤立或末端原子时去掉模板连接点原子，目标为末端 H 时替换该 H，其他目标元素保留。按住左键拖动调整片段朝向，松开合为一步历史；Esc、切换工具/标签和失焦取消未提交操作。当前仅支持直接键，周期网络和非末端目标被拒绝。
- 选中一个末端原子，可定义其整个显式键连接分量并填写名称、库名，后台保存到 `%LOCALAPPDATA%\AtomX\fragments`。每项使用普通 `.atomx` 文件，唯一选中原子标记连接点；上限 512 原子、2048 键、1 MiB。首次使用异步读取至多 128 项 / 8 MiB，异常文件跳过并提示。保存用临时文件和唯一名称，不覆盖已有项。
- 预览只保存小模板的坐标，静止时缓存结果，不复制大型体系或上传 GPU。结构仍使用现有 D3D11 渲染，无新增运行依赖。接枝保留既有键级、原子科学属性及显示标记；模板标量属性随新原子添加，向量属性随片段旋转。无对应属性的新行标记为缺失。
- `.atomx` 升为 v3，仍读取 v1/v2，新增片段库项键与连接点索引。各创作标签独立保存它们；自定义库项本体不嵌入结构文档，跨机器复用需复制库文件，已经放置的原子与键完整保存。
- 核心测试覆盖独立放置、末端 H 替换、重原子保留、非法连接点、过期起点、属性/颜色索引、向量旋转、自定义保存重载及拒绝覆盖。真实 ImGui 事件覆盖浏览器按钮、拖动预览/Esc、整步历史、标签索引恢复、自定义定义后台保存和多标签隔离。格式测试覆盖 v1/v2/v3；核心、界面、格式和实际 RTX 5090 D v2 GPU 图像测试全部通过。
- 最新原生 AtomX 中实际打开浏览器、选择羟基、双击预览另一末端 H 更换连接点，在甲烷末端 H 上拖动接枝；原子数 5→6，组成 CH4→CH4O。Ctrl+Z 恢复 5，Ctrl+Y 恢复 6，切回选择工具清除预览后按 Ctrl+S 保存验收文档。
- 本阶段不是完整化学绘制器：未自动检查完整价态、杂化、碰撞或优化几何；此前尚缺已有片段连接；现已按下文规则补齐。金属占位元素替换及完整模板集仍缺。

### 运动分组验收

- 修改菜单、视口右键菜单和右侧面板可打开分组窗口。从当前选择创建命名分组、改名、选择整组、取消单组/全部分组；取消只移除分组信息，保留原子和键。一个原子只能属于一组，重复归属在记录历史前拒绝，最多 512 组。
- 自动分组在后台以并查集遍历显式键，不按原子距离猜测拓扑；独立原子也分组，带周期边界键的整个连通网络跳过。分组期间暂停结构操作，避免将结果应用到改变后的体系。列表按结构版本缓存，并裁剪不可见行，不在每帧遍历全体系。

## Layer Builder 现场核对与实现

- 首轮实际打开本机 MS 的 Build → Build Layers，查看 Define Layers、Layer Details、Matching、Options 四页；移动原先部分越出屏幕的窗口后核对选项。当时临时非周期分子没有可用来源，因此该阶段未在 MS 中执行构建。后续周期来源的实机构建见下节。
- 几何规则据已安装官方帮助 `core/builders/layers_overview.htm`、`dlglayerbuilderdefine.htm`、`dlglayerbuilderdetails.htm`、`dlglayerbuildermatching.htm`、`dlglayerbuilderoptions.htm`、`surftaskslayer.htm`、`crysttaskslayer.htm`：两至三层、层上方真空、分数面内偏移、任选来源/平均 a、b、γ、保持体积/厚度、来源朝向、5% 失配提示。MS 默认完整分子切割、A/B 翻转及模拟用 Confined shear 与本轮实现有区别。
- AtomX 入口为创作模式“构建 → 构建叠层”，查看模式 Build → Build Layers，或 Ctrl+P 搜索 Build Layers。查看模式入口先创建独立创作副本。结果替换当前创作体系并记录一步历史，来源标签保留；可暂存工作区快照。来源为所选标签当前帧的源数据；修改器结果须先创建创作副本。
- 支持右手 3D 晶体及 a/b 周期的 2D 表面，禁止采样与退化晶胞。晶体先按周期归一化到单胞；面内匹配时分数坐标不变，c 的面内分量随晶格变换，保持体积时以旧/新面内面积调整法向厚度。晶体输出沿调整后的 c 累积，表面输出沿法向累积；每层上方真空均沿法向增加，表面输出忽略末层真空。表面来源以原子法向跨度为厚度，去掉原来源的外部真空；零厚度单原子层需非零层间真空。
- 保留元素、显式键级和面内周期键，并随面内归一化重算键周期像；切断层的法向边界键，不推断新跨层键。合并各层标量/矢量属性并保持原子行对应，缺失值补 NaN；完整自定义颜色保留。矢量值保持来源语义，不自动猜测 Force/Velocity 等任意列的应变变换；源/目标基底保存于 `AtomX.LayerBases` 表。全局属性与普通表按 Layer1/2/3 命名空间保存，避免伪造合并总能量等值。运动分组编号按来源重新分配。
- `AtomX.Layer` 标记层成员，`AtomX.Layers` 保存名称、起始原子、数目、真空、偏移、厚度及失配；它们使用现有科学属性格式随 `.atomx` 保存，不升级文档版本。输出为 P1 / p1，不沿用来源的对称关系。
- 构建只在点击时复制来源快照并启动后台任务；普通 UI 预览只访问晶格和原子数，不逐原子扫描或生成邻居。采用当前完整载入原子上限，不沿用旧叠层 60000 限制。不添加运行时包或更换 GPU 渲染路径。

### 完整分子切割与层翻转

- 后续现场操作在 MS 中通过 File → Import 导入本任务的 P1 斜晶胞（a=6、b=7、c=10 Å、γ=60°，C/O 两原子），在 Build Layers 的 Layer Details 中实际选择 Flip A。Matching 页显示 γ=120°，点击 Build 后生成独立 Layer.xsd；仅保存本任务的新结果，未改动用户原有文档，也未使用 MS Calc。
- 已安装官方帮助明确 A/u 对应 a、−b、−c，B/v 对应 −a、b、−c，匹配角取 180°−γ；Default 切割按分子质心归属保留连通原子，以暴露原子的范德华半径修正厚度。MS 测试结果 c=8.220000 Å，符合两个原子法向跨度 5 Å 加 C/O 半径 1.70/1.52 Å。现场的单层结果所存 A/B 矢量夹角仍为 60°，与 Matching 显示值不同；此差异尚未解释，不能声称已验证 MS 所有输出朝向与 AtomX 完全一致。AtomX 采用上述官方补角规则，斜晶胞测试验证翻转后匹配无额外应变、键长保持。
- AtomX 每层增加“原子切割 / 完整分子（质心归属）”及“不翻转 / A/u / B/v”。表面来源不重复切割，翻转仍可用。完整分子仅由已有显式键及周期像确定；无键原子单独处理，不计算距离邻居。有限连通分量先展开周期像，再以质量加权质心整体归属单胞，不逐原子切断分子。具有非零周期绕数的无限键网络明确拒绝，用户可改用原子切割。
- 正且有限的逐原子 Mass 优先用于同位素/自定义质量；缺少该列时采用内置元素质量，数据对照本机安装的 MS 元素表。厚度使用 AtomX 现有 Bondi 范德华半径，不替换现有元素外观；部分元素与 MS 的半径表不同，缺少已用元素半径时拒绝完整分子切割。此功能不提供化学价态推断或跨层自动键合。
