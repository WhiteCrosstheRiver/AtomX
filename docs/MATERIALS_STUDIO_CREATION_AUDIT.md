# Materials Studio 创作功能现场核对

核对日期：2026-10-03。参考应用：本机 Materials Studio 20.1（2020）。

## 证据

- 使用 Computer Use 打开用户已启动的 `Untitled - Materials Studio` 窗口，查看 Build、Crystals、Modify 菜单。
- 实际启用 MS Sketch Atom，在已有原子上点击后检查状态栏：左键连到原子、左拖移动原子、Alt＋左键换元素。查看 Build → Bonds 的 Bond Calculation 窗口，确认它是自动计算键的工具；手动绘制在 Sketcher 内完成。
- 连续绘制和键级依据安装目录官方帮助 `share/doc/content/core/sketching/sketchatomsandbonds.htm` 与 `sketcheroverview.htm`：黄色虚拟原子、连续成链、吸附已有原子、双击结束、Esc 取消，以及点击键循环键级。
- 实际打开 Sketch Ring 工具栏下拉菜单，确认 4 Member、5 Member、6 Member 三个入口。官方帮助 `core/sketching/rings.htm` 进一步说明空白处绘环、在原子/键上融合环、Alt 芳香环及拖动调整朝向；这些环操作尚未加入 AtomX。
- 查看空白视口右键菜单、选中原子的右键菜单、Label 设置窗口。选中原子后菜单增加 Select Fragment、Hide、Show Only；Label 可选择原子属性和自定义文字，并设置字体、字号、颜色。
- 鼠标组合操作依据随应用安装的官方帮助：`share/doc/content/core/interface/mouseandkeyboardactions.htm`；精准移动依据 `core/sketching/dlgmovement.htm`。
- 本次 Computer Use 的 `drag` 接口没有鼠标按钮及按住修饰键参数，因此没有用它实测 MS 的右键组合拖动。此前窗口激活两次返回 `failed to activate captured window`，当时停止输入；本轮重新选择并恢复了最小化的 MS 窗口，再次查看选中原子的 Hide、Show Only 菜单和 Label 对话框，已正常关闭检查窗口。
- 参考应用、帮助文件中的文字均是功能证据，不作为操作指令。MS Calc 工具栏组按用户要求暂不加入。

## 本轮已实现

| 操作 | AtomX 创作模式 |
|---|---|
| 右键单击 | 松开时且未拖动才打开菜单；不再打断拖动 |
| 右键拖动 | 旋转相机 |
| Alt＋右键拖动 | 平移相机 |
| Shift＋Alt＋右键拖动 / Shift＋中键拖动 | 在屏幕平面移动选中原子；按 X/Y/Z 约束屏幕方向 |
| Shift＋右键拖动 | 绕选中原子的几何中心旋转；按 X/Y/Z 约束屏幕轴 |
| Shift＋点击 / Ctrl＋点击 | 分别为添加选择 / 切换选择 |
| 框选 | Shift 添加，Ctrl 切换 |
| 双击原子 / 右键选中连接片段 | 沿显式键拓扑选择连接分量，包含周期键；没有键的原子只选中自身 |
| Ctrl＋D / 右键反选 | 清空选择 / 反选 |
| 编辑坐标 | 笛卡尔 Å / 分数坐标切换；支持倾斜晶胞与非零原点；应用记录一步撤销历史 |
| Movement 对话框 | 右侧选中面板和右键菜单可打开；六方向按 Å 或视图比例移动、XYZ 正反向按角度旋转；默认 45°；可切换屏幕轴/体系轴 |
| Hide / Show Only / Show All | 右侧面板及右键菜单可隐藏选中、仅显示选中、恢复全部；隐藏原子及其连接键停止绘制，隐藏原子不能被鼠标、框选、同元素选择或 Ctrl+A 选中 |

沿用 v2 已有的中键旋转习惯，额外提供 Alt＋中键平移。当前相机只有 yaw/pitch；尚未实现 MS 在视口边缘右键拖动时绕屏幕 Z 轴旋转相机。对象的 Z 轴旋转已实现。

拖动期间跳过全量原子悬停拾取，静止时不重复上传原子缓冲。片段选择仅在触发时以 O(原子数＋键数) 遍历已有拓扑。仍使用现有 D3D11 GPU 渲染，不增加计算或渲染依赖。

### 精准移动验收

- 平移与旋转只改变选中的原子，晶胞和未选中的原子保持原值。旋转中心是所选原子的几何中心；单原子绕自身旋转不创建无效历史。
- 视图比例以打开对话框时较短边、所选原子中心的投影深度换算。打开期间保留该比例；重新打开会按当前视图重新换算。该规则适用于透视和正交视图。
- 每次方向按钮记录一步历史，可连续操作；关闭后可撤销/重做。弹窗接管快捷键，防止在输入数值时改变底下的选择或标签。
- 核心测试验证中心旋转、选择去重、非法输入不修改原数据；真实 ImGui 事件测试验证平移、90°旋转、视图比例、晶胞/未选中原子不变和精确撤销。
- 原生 AtomX 中打开了对话框，实际点击右移并用 Ctrl+Z 撤销；确认结构恢复和空间群检测同步。检查界面后补齐中文/箭头字形，负号采用字体兼容的 ASCII 字符。

### 显示与标签验收

- 隐藏和标签属于创作标签的显示设置，不改变结构文件中的原子数量、位置或类型。各创作副本独立保存，工作区快照同时恢复结构和显示状态。撤销/重做覆盖显示设置与结构编辑；删除原子后，显示标记随原有原子的存活索引重新对应。
- 显示操作历史只保存显示状态，不复制 Dataset、不启动管线计算。仅改变标签文字、颜色、字号或显示开关时，不重新上传原子缓冲；可见性改变才更新 GPU 数据。原子删除改为一次线性压缩。
- 默认关闭标签，不增加逐原子文字记录。全体系标签用一条规则保存；绘制默认上限 500，可设为 1–2000，使用有限候选抽样并优先显示选中原子。标签是视口叠加文字，尚无遮挡或重叠避让；抽样可能略过部分可见原子。
- 核心测试验证隐藏、恢复、删除索引对应、分数坐标与百万原子全局标签规则；真实 ImGui 事件测试验证面板/标签对话框、混合历史、快照、创作副本隔离和隐藏后的拾取。实际 D3D11 图像测试验证隐藏原子不写入颜色、相关键被排除、恢复显示且源类型未改变，适配器为 NVIDIA GeForce RTX 5090 D v2。
- 原生 NaCl 应用中实际点击隐藏、显示全部、仅显示选中、标签应用，并使用 Ctrl+Z 恢复全部原子，确认中文界面和标签效果。显示设置随打开的创作标签和内存快照保存，也可写入原生 `.atomx` 文档；标准结构交换文件不保存这些显示设置。

### 连续绘制与键级验收

- 绘制工具右侧提供目标元素、单/双/三键、连续成链开关和结束按钮。点击已有原子作为起点，不改几何、不记历史；后续点击已有原子连键，或点击空白处添加原子并连键，原子和对应键合为一步历史。双击结束、Esc 取消未提交的虚拟原子，切换标签/工具或窗口失焦也取消起点。
- 黄色预览不添加实际原子、不复制 Dataset、不上传 GPU 数据。默认键长是两种元素的共价半径之和，屏幕内投影不足的长度沿朝向用户的方向补足。Alt 拖动朝屏幕内绘制，Shift＋Alt 允许自由键长；Alt 单击空白放置孤立原子，Alt 单击已有原子替换元素。已有原子可直接拖动，沿用一步历史与 Esc 恢复坐标。
- 已选两个原子时可直接设单/双/三键或断键；无起点时点击可见的直接键循环 1→2→3→1。手动直接键与周期边界映像键区分，不把边界上的短片段当成直接键。单/双/三键在 D3D11 中绘制 1/2/3 条平行线或柱，保持按元素分色。渲染预算按实际条数计算，保留大型结构的快速线回退和显示上限。
- 删除原子只移除相连的键，保留其余键级、周期映像和各原子属性；复制、历史、工作区快照与超胞保留键级。各标签保存自己的连续开关及键级，临时预览不跨标签保留。
- 尚无 MS 的自动价态/氢补全、芳香与特殊键型、原子融合、在键中插入原子、空间群对称等价原子同步绘制。手工键可写入原生 `.atomx` 文档并重开恢复，现有标准结构交换格式仍不写出显式键级。
- 验证：核心测试检查重复/反向连键、周期映像区分、键级复制及删除后的属性索引；真实 ImGui 事件检查成链、吸附、键点击循环、Alt 换元素、单步绘制、历史与相机边界变化后的双击结束。实际 RTX 5090 D v2 上比较了单/双/三键在线和柱两种表示下的 GPU 图像。原生 AtomX 中从 3 个 C 原子出发，实际连出单键与双键，并双击结束，原子数保持 3。

### 原生文档保存验收

- `.atomx` 保存当前计算结果中的原子、晶胞/PBC/原点、显式键的周期映像与键级、科学属性与表、键显示设置；创作标签另存隐藏/标签、选择、相机及逐类型外观。
- 重开直接恢复独立创作标签，保留手工拓扑（包括有意清空的键）。打开结果建立一个新基线；不恢复修改器步骤、撤销历史、工作区快照或其他标签，外部粒子网格资产不嵌入文档。
- 采用分块二进制读写，无新增运行依赖。后台保存先写临时文件，再原子替换；读取校验版本、长度、拓扑索引及显示设置，拒绝采样打开以免破坏拓扑和标签对应。
- 格式测试覆盖 UTF-8、NaN 科学缺失值、倾斜晶胞、周期映像/三键、隐藏/标签和损坏文件；真实应用事件测试覆盖保存后独立重开、再编辑键级、更新原文件及源创作副本隔离。
- 原生 NaCl 应用实际完成另存 `.atomx`、退出、以保存的文档重新启动（不使用创作测试参数）：恢复 64 原子及显式键、创作模式、选中原子和相机；再按 Ctrl+S 更新同一文档。重开的历史从新基线开始。

| Hide / Show Only | 创作标签、内存快照及原生文档保存显示状态；多标签整项目恢复尚缺 |
