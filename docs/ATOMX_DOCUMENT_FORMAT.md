# AtomX 原生文档 v3

`.atomx` 保存一个当前结果及其创作显示设置，不要求额外运行库。文件不是 Materials Studio 的 XSD，也不是跨软件交换格式。

## 保存内容

- 元素类型、笛卡尔位置、晶胞矩阵、PBC、原点和注释。
- 显式键：两端索引、周期映像、单/双/三键级和芳香键，以及键显示设置。编码 4 代表芳香键（1.5），不是四重键。
- 原子标量/向量属性、指定颜色、属性分量名称、全局属性与科学数据表。缺失值 NaN 原样保留。
- 创作模式、单视口相机、原子大小/形状与逐类型外观、选择、工具/目标元素/键级/连续开关、环大小、片段库项键与连接点索引、属性面板页。
- 隐藏标记、默认及逐原子标签、文字样式与数量上限。

保存的是管线计算后的结构。修改器步骤、撤销/重做历史、工作区快照、其他标签及外部自定义网格文件不包含在文档中。重开建立一个新编辑基线。

## 编码与校验

开头为 8 字节 ASCII `ATOMXDOC`，随后为小端 `uint32` 版本号 3。数值使用小端定宽整数和 IEEE 浮点；布尔为 0/1 的 `uint8`。字符串为 `uint64` 字节长度和 UTF-8 内容，数组为 `uint64` 元素数和元素数据。Atom 为三个 float32 坐标加 uint32 类型索引（16 字节）；键的端点、映像和键级分别写入，不含 C++ 对齐填充。

v2 在标签块之后、`DONE` 之前增加一个 int32 环大小（4–6），工具枚举增加 Ring=5，键级允许芳香编码 4。v3 在环大小后追加片段库项键字符串与 int32 连接点索引（0–511），工具枚举增加 Fragment=6。仍读取 v1/v2：v1 环大小默认为 6，不能声明环工具或芳香键；v2 不能声明片段工具；旧文档片段默认为 `builtin/methyl`、连接点 1。旧版本程序不能读取新写出的 v3 文档。

自定义片段库用普通 `.atomx` 文件保存：title 为名称、basedOn 为库名、selection 中唯一末端原子为连接点。创建中引用的自定义库文件不嵌入普通结构文档；缺少对应本机库项时不提供放置预览，需重新选择。已经放置的原子与键仍完整保存在结构文档内。

数据块依次为类型、原子、晶胞/PBC/原点/注释、键/键样式、原子颜色、科学属性与表、创作视图/工具/逐类型样式、隐藏/标签。末尾为 ASCII `DONE`。准确字段顺序以 `src/creation_document.hpp` 为准；修改格式需更新版本并提供对应读取分支。

读取分配前检查声明长度与剩余字节，校验索引、键级、有限坐标和视图设置，拒绝未知版本、截断或额外尾随内容。原生文档要求全量读取，超过原子预算时报错，用户须提高预算后重开。读写每 1 MiB 检查取消状态。

界面保存异步执行，先写同目录临时文件，成功后通过原子替换发布，避免失败覆盖已有文档。创作 Ctrl+S 首次选择保存路径，保存成功后该标签记住文档位置，后续 Ctrl+S 更新该文件。Save As 可另选路径；各标签独立保存文档位置。
